# THETA Open Source Workbench

Use the existing web interface without an account or simulated user.

See [startup and edition boundaries](../docs/opensource-agent.md), [Agent CLI and backend](../agent/README.md), and [confirmation cards](../agent/docs/web-confirmation-cards.md).

Run `npm ci`, copy `.env.example` to `.env.local`, start the Agent backend, then run `npm run dev`. Open http://127.0.0.1:4320 and enter the workbench.
